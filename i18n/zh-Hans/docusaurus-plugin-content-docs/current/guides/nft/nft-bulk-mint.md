The [chia-nft-minting-tool](https://github.com/Chia-Network/chia-nft-minting-tool "chia-nft-minting-tool") GitHub repository has been archived. Feel free to clone it for your own usage, but CNI will no longer maintain or support it. As an alternative for minting NFTs in bulk, we recommend [MintGarden Studio](https://mintgarden.io/mint/studio).

Note that the [CLI](/guides/nft-cli/) and [RPC](/guides/nft-rpc/) tools for minting individual NFTs continue to be actively supported.
